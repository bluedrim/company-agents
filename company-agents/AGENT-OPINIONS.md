# Agent Opinions

각 담당 에이전트가 CEO 지시에 대해 독립적으로 의견을 제출하는 문서입니다.
모든 에이전트는 동시에 작성한다고 가정합니다.

## Opinion Template

```text
Agent:
핵심 의견:
바로 시작할 일:
필요한 협업:
리스크:
1주 안 산출물:
CEO 결정이 필요한 부분:
```

## COO Agent Opinion

Agent: COO Agent
핵심 의견: 운영 루프가 작동하려면 업무 상태, 담당자, 의존성, 완료 기준이 한곳에 모여야 한다.
바로 시작할 일: `TASK-BOARD.md`를 만들고 모든 팀의 첫 주 업무를 `Ready` 상태로 정리한다.
필요한 협업: 모든 Manager가 팀원별 업무와 완료 기준을 제출해야 한다.
리스크: 업무가 너무 추상적이면 진행 상태를 판단할 수 없다.
1주 안 산출물: 전체 업무 보드, 병목 로그, 주간 운영 리듬
CEO 결정이 필요한 부분: 이번 주 최우선 목표 1개와 보조 목표 범위

## CFO Agent Opinion

Agent: CFO Agent
핵심 의견: 모든 실행 업무는 비용과 예상 효과를 함께 기록해야 한다.
바로 시작할 일: 팀별 예상 비용과 필요한 도구 목록을 수집한다.
필요한 협업: Operations Team, Marketing Team, Engineering Team의 비용 계획
리스크: 초기부터 유료 도구와 외주를 늘리면 현금 소진 속도가 빨라진다.
1주 안 산출물: 첫 달 운영 예산 초안, 비용 승인 기준
CEO 결정이 필요한 부분: 지출 승인 한도와 유료 도구 도입 기준

## CTO Agent Opinion

Agent: CTO Agent
핵심 의견: 병렬 실행을 위해 기술 업무는 제품 요구사항, 데이터 추적, 배포 흐름과 연결되어야 한다.
바로 시작할 일: MVP 기술 요구사항과 개발 환경 기준을 정리한다.
필요한 협업: Product Team의 MVP 범위, Data Team의 이벤트 정의, Legal Team의 개인정보 기준
리스크: 제품 범위가 불명확하면 기술 설계가 흔들린다.
1주 안 산출물: 기술 스택 후보, MVP 아키텍처 초안, 배포 체크리스트
CEO 결정이 필요한 부분: MVP에서 반드시 포함할 핵심 기능

## CPO Agent Opinion

Agent: CPO Agent
핵심 의견: 회사 운영보다 먼저 고객 문제와 MVP 범위를 선명하게 해야 한다.
바로 시작할 일: 타깃 고객, 핵심 문제, MVP 필수 기능을 정의한다.
필요한 협업: Sales Team의 고객 반응, Customer Success Team의 온보딩 가설, CTO Team의 구현 난이도
리스크: 너무 많은 기능을 동시에 넣으면 출시가 늦어진다.
1주 안 산출물: MVP 범위 문서, 고객 인터뷰 질문지, 제품 우선순위 표
CEO 결정이 필요한 부분: 첫 번째로 집중할 고객군

## CMO Agent Opinion

Agent: CMO Agent
핵심 의견: 제품이 정교해지기 전에도 가치 제안과 초기 채널 실험은 시작해야 한다.
바로 시작할 일: 한 문장 가치 제안과 첫 캠페인 메시지를 만든다.
필요한 협업: Product Team의 고객 문제 정의, Sales Team의 리드 반응, Data Team의 캠페인 지표
리스크: 메시지가 넓으면 아무 고객에게도 강하게 닿지 않는다.
1주 안 산출물: 포지셔닝 초안, 채널 실험 계획, 콘텐츠 캘린더
CEO 결정이 필요한 부분: 브랜드 톤과 초기 시장 포지션

CEO 결정이 필요한 부분: 접근할 첫 고객 세그먼트

## Customer Success Agent Opinion

CEO 결정이 필요한 부분: 고객에게 약속할 수 있는 최소 성과

## HR Agent Opinion

Agent: HR Agent
핵심 의견: 에이전트 조직도 역할, 책임, 보고 방식이 명확해야 병렬 작업이 가능하다.
바로 시작할 일: Manager와 Staff의 책임 경계와 보고 템플릿을 정리한다.
필요한 협업: COO Team의 운영 리듬, 모든 Manager의 역할 정의
리스크: 책임이 겹치면 결정이 늦어지고 소유권이 흐려진다.
1주 안 산출물: 역할 책임표, 보고 템플릿, 온보딩 체크리스트
CEO 결정이 필요한 부분: 최종 의사결정 권한의 위임 범위

## Legal Agent Opinion

Agent: Legal Agent
핵심 의견: 고객 접촉, 데이터 수집, 외부 도구 사용에는 최소한의 법무 기준이 필요하다.
바로 시작할 일: NDA, 개인정보 수집 항목, 외부 도구 사용 체크리스트를 만든다.
필요한 협업: Sales Team의 고객 접촉 방식, CTO Team의 데이터 구조, CMO Team의 마케팅 문구
리스크: 검토 없는 고객 약속이나 데이터 수집은 나중에 큰 비용이 된다.
1주 안 산출물: 법무 체크리스트, 개인정보 기준, 계약 검토 항목
CEO 결정이 필요한 부분: 감수 가능한 법적 리스크 수준
