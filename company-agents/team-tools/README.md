# Team Tool Templates

이 폴더는 팀별 도구를 실제로 사용할 수 있게 만드는 템플릿 모음입니다.

- `tool-registry.json`: 팀별 도구 목록을 기계가 읽을 수 있는 형태로 저장합니다.
- `tool-template.md`: 새 도구를 추가할 때 복사해서 쓰는 기본 템플릿입니다.
- `generic-register.csv`: register, tracker, board류 도구에 공통으로 쓸 수 있는 CSV 헤더입니다.
- `generic-decision-brief.md`: 의사결정 브리프 기본 양식입니다.
- `generic-review-checklist.md`: 리뷰 체크리스트 기본 양식입니다.

팀별 세부 도구 목록은 [TEAM-TOOLS.md](../TEAM-TOOLS.md)를 기준으로 관리합니다.
