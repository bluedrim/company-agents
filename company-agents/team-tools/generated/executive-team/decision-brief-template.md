# Decision Brief Template

- Owner Team: Executive Team
- Type: Brief template
- Source Template: generic-decision-brief.md
- Purpose: 선택지, 근거, 추천안을 한 페이지로 요약
- Expected Output: 의사결정 브리프

## When To Use

- 선택지, 근거, 추천안을 한 페이지로 요약
- 업무 owner, 상태, 다음 액션을 명확히 남겨야 할 때 사용한다.
- 다른 팀 리뷰가 필요한 산출물을 표준 형태로 공유할 때 사용한다.

- Inputs
- Decision or Output
